# Project Setup

## Purpose
Set up a new software project on the Mac.

## Workflow
1. Identify the project directory.
2. Verify that the directory exists.
3. Open the project in Cursor.
4. Check whether Git is initialized.
5. Initialize Git only if necessary.
6. Report the final status.

## Safety
- Never invent filesystem paths.
- Never overwrite existing files.
- Ask approval for high-risk actions.
