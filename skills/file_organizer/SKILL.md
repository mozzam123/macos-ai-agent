# File Organizer

## Purpose
Organize files into meaningful folders.

## Workflow
1. Inspect the target directory.
2. Identify file types.
3. Determine the folder structure.
4. Create missing folders.
5. Move files into appropriate folders.
6. Verify the final structure.

## Guidelines
- Never assume a directory path.
- Use paths returned by discovery tools.
- Do not delete files.
- Verify operations after execution.
